## Especificações Técnicas (Para TI)

**Stack:**
- Frontend: Next.js 15 + React 18 + TypeScript
- Backend: Next.js API Routes
- Database: PostgreSQL (Neon) + Prisma ORM v6.16.3
- UI: Tailwind CSS v4
- PWA: next-pwa + Service Workers
- Auth: JWT + httpOnly Cookies (admin)

**APIs:**
- 18 endpoints RESTful completos
- Validação server-side robusta
- Error handling consistente
- Status codes HTTP corretos

**Performance:**
- Build: 2.7s
- First Load: < 111kB/página
- API Response: < 300ms (p95)
- PWA Score: 100%

**Segurança:**
- HTTPS obrigatório
- Validação de inputs
- Proteção CSRF
- httpOnly cookies
- Fingerprint em dois níveis
